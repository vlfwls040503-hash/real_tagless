## 5. 한계

- 영상이 **자유흐름 dominant** (ρ ≤ 0.5 시점 80%+) → 고밀도 검증 불가
- ROI 면적 2 m²에 사람 수가 정수라 **밀도가 이산 5값**(0.5/1.0/1.5/2.0/2.5)에만 분포
- 게이트 진입 직전 영역이라 **자유보행이 아님** (가속/감속 혼재) → Weidmann 곡선 직접 비교 시 모든 밀도에서 영상이 낮음
- 호모그래피 perspective 항이 거의 0 → 사선 카메라 외삽 시 거리 환산 오차 가능
- 트래킹 ID 끊김(단말기 차폐) 다수 → 트랙 길이 p50 = 30 frame (1초)로 짧음
