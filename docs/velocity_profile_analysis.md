## 핵심 발견 — 게이트 vs 시스템 관점 비교 (p=0.5)

- **게이트 부근(x=11~13) 평균 속도**: cfg 2 = 0.65 m/s, cfg 4 = 0.70 m/s
- **에스컬 대기(x=23~28) 평균 속도**: cfg 2 = 0.37 m/s, cfg 4 = **0.34 m/s**
- 차이 (-0.03 m/s) → cfg 4가 에스컬에서 더 느림 (병목 전이)

## 병목 전이 공간적 증거 (3줄 요약)

1. 게이트 관점 최적 (cfg 4)은 게이트 부근 속도를 높이지만 에스컬 대기(x=23~28) 구간에서 속도 dip이 더 깊음 — 병목이 게이트→에스컬로 공간적으로 이동.
2. 시스템 관점 최적 (cfg 2)은 게이트에서 다소 감속하지만 에스컬에서 흐름 유지. 두 병목을 균형 분배.
3. 모든 시나리오에서 속도 최저점은 x=23~28 (에스컬 입구) 또는 x=11~13 (게이트) 중 하나로 수렴 — 병목이 공간적으로 두 곳에 고정. 정책 선택은 어느 쪽 병목을 줄일지의 trade-off.
